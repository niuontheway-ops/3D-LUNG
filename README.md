# 壶兰呼吸 · 人体肺脏三维解剖

面向手机课堂教学的交互式肺脏三维网页，由莆田学院附属医院呼吸与危重症医学科老崔制作。

在线访问：<https://niuontheway-ops.github.io/3D-LUNG/>

![手机访问二维码](手机访问二维码.png)

## 手机操作

- 单指拖动：旋转模型
- 双指开合：放大或缩小
- 底部工具栏左右滑动：切换肺叶、听诊、触诊叩诊、支气管图解和拆解模式
- 点击“肺叶”：打开肺叶选择与文字说明

## 教学内容

- 五个肺叶的识别、文字说明与单独显示
- 肺叶拆解与支气管树分支定位
- 八类呼吸音听诊示例及常见临床意义
- 胸部触诊、叩诊定位与常见异常变化
- 半透明肋骨、肩胛骨和胸壁教学叠加层

## 资源与许可

肺模型来自 E-learning UMCG，按 CC BY-NC-SA 4.0 使用；胸廓数据来自 BodyParts3D。详细署名、链接与许可见仓库中的《来源与许可.txt》和《胸廓模型来源与许可.txt》。本项目用于非商业课堂教学。
